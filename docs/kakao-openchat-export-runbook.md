# Kakao Openchat Export Runbook (고정 경로)

## 목표
오픈채팅방만 대상으로, 아래 1세트를 **방마다 완주**한다.

## 고정 1세트 경로 (절대 순서)
1. 카카오톡 메인창에서 **오픈채팅 탭** 확인
2. 오픈채팅 목록에서 방 진입 (더블클릭 또는 Enter)
3. 채팅방 본문 우상단 **햄버거(≡)** 클릭
4. **채팅방 설정** 클릭
5. **대화내용 관리** 클릭
6. **텍스트 파일로 저장** 클릭
7. 저장 경로/파일명 확인 후 **저장** 클릭
8. **대화내용 내보내기 완료** 팝업에서 **확인** 클릭
9. 채팅방 창 닫기 (Cmd+W)
10. 다음 방으로 이동

---

## 실행 규칙
- 텔레그램/다른 앱 터치 금지
- 오픈채팅 탭이 아니면 즉시 전환 후 시작
- **한 방 완주 확인(8번 확인 클릭)** 전에는 다음 방으로 넘어가지 않음
- 실패 시 즉시 복구 후 같은 방 재시도 (최대 2회), 이후 다음 방으로 이동하고 실패 로그 기록

---

## 실패 복구 규칙
### A. 댓글 달린 메시지 창으로 빠짐
- Esc 또는 Cmd+W로 닫고
- 원래 채팅방 본문으로 복귀 후 3번부터 재시도

### B. 햄버거 오클릭/미반응
- 같은 방 본문 포커스 다시 잡고 햄버거 재클릭
- 2회 실패 시 해당 방 실패로 기록 후 다음 방

### C. 팝업/설정창 ID 변경
- 고정 ID 사용 금지
- 매 단계마다 현재 열린 카카오톡 창 목록 재조회 후 타겟 재선정

### D. 카카오톡 창 종료
- `open -a KakaoTalk` 재실행
- 오픈채팅 탭 확인 후 중단된 방부터 재개

---

## 로그 포맷 (필수)
- 성공: `SUCCESS | <timestamp> | <room_title> | export_done`
- 실패: `FAIL | <timestamp> | <room_title> | <reason>`
- 경로 이탈: `ISSUE | <timestamp> | <room_title> | <issue> | recovered=<yes/no>`

로그 파일: `priceit-starter/logs/kakao-export-runbook.log`

---

## 실시간 파악사항(즉시 반영)
- `cmd+shift+s`는 본 작업 경로에서 오작동/무반응 가능성이 있어 기본 경로로 사용하지 않음.
- 햄버거 오클릭 시 `댓글 달린 메시지`/달력(`최근`) 팝업으로 빠질 수 있음.
- 달력/댓글 팝업 발생 시 즉시 `Esc` 또는 `Cmd+W`로 닫고 채팅방 본문으로 복귀.
- 햄버거 후보 좌표(채팅방 창 기준): 우상단 우측 영역(예: canvas x≈740~770, y≈92). 단, 아이콘 오탐(달력/댓글) 가능성이 있어 클릭 후 창 변화 검증 필수.
- 현재 실측 기준(방 `과일 농수산...`): mac-use OCR 요소 `"4="`의 중심점 `(740,92)`가 우상단 메뉴 근처 기준점으로 반복 검출됨.
- 사용자 확인: 채팅방 설정 단축키는 `⌥⌘,`(Option+Command+,).
- 실패 판정 기준(사용자 정의): `다음 코스로 넘어가지 않으면 실패`.
- 핵심 실패원인(확정): `텍스트 파일로 저장` 클릭 위치 오판으로 다음 코스 미진입.
- 운영 원칙 추가: 임의 좌표 사용 금지, 사용자가 지정/검증한 좌표만 사용.
