# Kakao 오픈채팅 Top2 좌표 세트 (최고집/팜허브)

기준 창:
- 앱: 카카오톡
- window id: 3052
- 화면: 오픈채팅 목록

## 방 선택 좌표 (목록)
- 최고집 행 클릭(현재 캡처 기준): canvas `(374,259)`
- 팜허브 행 클릭(현재 캡처 기준): canvas `(627,812)` 근처 텍스트 라인

## 내보내기 플로우(사용자 검증값)
1. 방 진입
2. 채팅방 설정 단축키: `⌥⌘,`
3. `텍스트 파일로 저장` 클릭: `(1002,192)`
4. 저장: `Enter`
5. 완료 확인 클릭: `(1068,320)`
6. 닫기: `Cmd+W`

## 주의
- 목록 스크롤 위치가 바뀌면 팜허브 좌표는 변동될 수 있음.
- 실행 전 오픈채팅 목록이 상단 기준으로 정렬되어 있어야 함.
