# MVP v1 - 데이터 정합성/중복처리/기본 리포팅 안정화

## 구현 코드
- `src/pipeline.py`
  - 메시지 해시 기준을 `room|sender|created_at|line`으로 변경.
  - 10분 윈도우 중복 차단(`duplicate_window_10m`) 추가.
  - 스킵 사유를 `ingestion_audit` 테이블에 기록.
- `src/db.py`
  - `ingestion_audit` 테이블 및 인덱스 추가.
  - 메시지 조회용 보조 인덱스(`idx_messages_room_line_time`) 추가.
- `scripts/verify_v1.py`
  - 중복키/감사로그/기본 볼륨 지표 확인 스크립트.

## 검증 방법
```bash
python3 -m src.init_db
python3 scripts/verify_v1.py
```

## 실패/리스크
- 현재는 `message_text` 기반 10분 윈도우 차단이라, 동일 공지가 실제로 재전송된 케이스를 누락할 위험이 있음.
- `ingestion_audit`는 누적성이라 장기 운영시 테이블 커짐(보관정책 필요).
