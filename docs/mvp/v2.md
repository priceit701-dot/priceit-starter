# MVP v2 - 파서 이벤트 품질 개선(가격/품절/지연/신규)

## 구현 코드
- `src/parser.py`
  - `입고 지연`류 문장이 `RESTOCK`으로 오인식되지 않도록 부정 힌트(`NEGATIVE_RESTOCK_HINTS`) 추가.
  - 대괄호 상품명 정제 규칙 강화(가격변동/품절예정 텍스트 제거).
- `tests/test_parser_rules.py`
  - 가격인상/지연공지/신규상품/품절 케이스 회귀 테스트 추가(4건).

## 검증 방법
```bash
python3 -m unittest tests/test_parser_rules.py
python3 scripts/eval_parser_farmhub.py
```

## 실패/리스크
- 벤치마크 샘플 수(20)가 작아 과적합 가능성 있음.
- 다중 이벤트(한 메시지에 인상+품절 동시) 지원은 아직 단일 이벤트 중심.
