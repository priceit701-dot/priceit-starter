# MVP v3 - API 확장 + 운영 대시보드 기본 UX 개선

## 구현 코드
- `src/api.py`
  - `GET /stats/quality` 추가: 이벤트 타입별 count/평균 confidence, ingestion skip reason 집계.
  - `GET /events/recent` 추가: 최근 이벤트 리스트(최대 200건).
- `web/dashboard.html`
  - 스킵 사유, 최근 이벤트 테이블, 자동 갱신 주기(7초) 반영.
- `scripts/verify_v3.py`
  - FastAPI TestClient로 신규/기존 엔드포인트 상태 검증.

## 검증 방법
```bash
python3 scripts/verify_v3.py
```

## 샘플 실행 로그(실행 결과 기반)
```text
V3_STATUS quality= 200 recent= 200 summary= 200
V3_COUNTS event_quality= 9 skip_reasons= 0
V3_COUNTS recent_items= 5 messages= 37367 events= 1513
```

## 실패/리스크
- TestClient 검증은 API 스키마/상태코드 중심으로, 프론트 렌더링 회귀(E2E)는 아직 미포함.
- skip_reasons=0은 "오류 없음"이 아니라 "최근 24h 수집 입력 없음"일 수도 있음(운영시간대 기준 보완 필요).

## 다음 버전 피드백(자체 리뷰)
- v4에서 controller와 정책 토큰 검증을 API 지표와 연동해 자동 PASS/FAIL 근거를 남겨야 함.
- 재시도/리커버리 결과를 구조화 로그(JSONL)로 남겨 운영 감사 가능하게 해야 함.
