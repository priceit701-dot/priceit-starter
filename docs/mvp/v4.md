# MVP v4 - 자동화 컨트롤러 실동작(정책+검증 토큰+리커버리)

## 구현 코드
- `automation/controller.py`
  - `EVIDENCE:` 토큰 뒤 JSON payload 파싱/필수 필드(`step`,`status`) 검증 추가.
  - 실패 코드 세분화: `INVALID_EVIDENCE_JSON`, `MISSING_EVIDENCE_FIELDS` 등.
  - retry 카운트 기반 `recovery_command` 훅 추가(`max_retry` 초과 시 트리거).
  - loop 로그에 `state/recovery/evidence`를 구조화로 기록.
- `automation/policy.json`
  - `max_retry`, `recovery_command` 정책 필드 확장.
- `scripts/verify_v4_controller.py`
  - PASS/FAIL 토큰 검증 로직 단위 확인 스크립트.

## 검증 방법
```bash
python3 scripts/verify_v4_controller.py
```

## 샘플 실행 로그(실행 결과 기반)
```text
V4_PASS {'pass': True, 'code': 'PASS', 'evidence': {'step': 'collect', 'status': 'PASS', 'count': 12}}
V4_FAIL {'pass': False, 'code': 'INVALID_EVIDENCE_JSON', 'evidence': None}
```

## 실패/리스크
- 실제 executor 연동은 여전히 정책 값 의존(`executor_command` 미설정 시 동작 불가).
- recovery command 실패시 2차 백오프 전략은 아직 없음.
