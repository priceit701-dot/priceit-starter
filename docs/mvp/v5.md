# MVP v5 - 운영 시뮬레이션(runbook 기반) + 릴리즈 후보 문서화

## 구현 코드
- `scripts/simulate_ops_runbook.py`
  - v1~v4 핵심 검증 스크립트를 순차 실행.
  - 결과를 `NEXT_STEP_OK` + `EVIDENCE:{...}` 토큰으로 출력하여 controller 정책과 정합성 유지.

## 검증 방법
```bash
python3 scripts/simulate_ops_runbook.py
```

## 샘플 실행 로그(실행 결과 기반)
```text
RUNBOOK_SIMULATION status= PASS
RUNBOOK_SIMULATION checks= 4 failed= 0
NEXT_STEP_OK
EVIDENCE:{"step": "runbook_simulation", "status": "PASS", "failed": 0}
- v1_integrity rc=0
- v2_parser rc=0
- v3_api rc=0
- v4_controller rc=0
```

## 실패/리스크
- 운영 시뮬레이션은 로컬 스크립트 체인 검증이며, 카카오 UI 자동수집기 실기기 시나리오(포커스 충돌/권한 오류)까지 100% 포함하지 않음.
- 성능/부하(대량 메시지 burst) 테스트는 별도 필요.

## 다음 버전 피드백(자체 리뷰)
- 시뮬레이션 결과를 CI(또는 cron)에서 주기 실행하도록 붙이면 회귀 탐지 속도 향상.
- 운영 알림 실패(텔레그램 API rate limit 등)에 대한 재전송 정책 문서화 필요.
