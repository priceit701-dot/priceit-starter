# 회사계정 데이터 보호 설정 (2026-02-12)

## 적용 목적
- 회사 계정 로그인 이후 내부 데이터가 외부로 배포/전송되지 않도록 운영 통제를 강화한다.

## 강제 운영 규칙
1. 외부배포 기본 금지
   - 내부 데이터는 기본적으로 외부 전송 금지
2. 명시 승인제
   - 사용자의 명시 지시가 있는 경우에만 1회성 전송 허용
3. 허용 대상 최소화
   - 기본 허용 대상: 사용자 본인 채널(telegram:7630623801)
4. 민감정보 마스킹
   - 토큰/로그인정보/원문 데이터는 공유 시 마스킹
5. 감사 추적
   - 외부 전송이 발생한 경우 목적/대상/파일을 로그로 남김

## 운영 메모
- 이 규칙은 `docs/agents/recording-policy.md`에 반영되어 상시 준수한다.
- 사용자가 허용 범위를 변경하면 즉시 문서/메모리를 동시 업데이트한다.
