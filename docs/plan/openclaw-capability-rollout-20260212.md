# OpenClaw Capability Rollout Plan (2026-02-12)

## 목적
- 병렬 오케스트라 운영을 전제로 OpenClaw 운영 가능 기능을 단계적으로 확장 적용한다.
- 사용자 감독 모델(감독=사용자, 오케스트라=에이전트)에 맞게 결과물 중심으로 운영한다.

## 적용 원칙
1. 기본은 병렬 레인(Research/Dev/Ops) 동시 실행
2. 사용자 신규 지시는 현재 작업보다 우선 반영
3. 모든 기능 적용은 결과물 파일 + 검증 로그 + 롤백 포인트를 남김

## 단계별 확장
### Phase 1 (즉시)
- 세션 병렬 운영 고정 (subagent 다중 레인)
- 리서치/개발/운영 분리 보고
- 셀러 화면 반영 우선

### Phase 2 (오늘)
- 자동 품질게이트: 결과물 존재, 7종 이벤트 순서, 드리프트 체크
- 매핑 리포트 자동 생성(미분류율/오분류율)
- 화면 안정성 운영(절전 방지/탭 비간섭)

### Phase 3 (다음)
- cron 기반 정기 검증/리포트
- 세션 헬스 모니터링(병렬 레인 상태 점검)
- 기능별 운영 런북 축적
