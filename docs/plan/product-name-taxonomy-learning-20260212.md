# 상품명 중심 분류 학습 기록 (2026-02-12)

## 1) 목적
- 상태값(긴급공지/품절) 중심이 아니라 **실제 상품명 중심**으로 파싱/대시보드/알림이 동작하도록
  - 쿠팡 식품 카테고리 구조

## 3) 식품안전나라 품목유형 체계(확인)
직접 메인 접근은 간헐적 실패가 있었으나, OpenAPI 정보 페이지는 정상 확인됨.

### 확인 URL
- 품목유형코드(OpenAPI 안내):
  - `https://www.foodsafetykorea.go.kr/api/openApiInfo.do?menu_grp=MENU_GRP31&menu_no=661&show_cnt=10&start_idx=1&svc_no=I2510&svc_type_cd=API_TYPE06`
- 식품원재료코드(OpenAPI 안내):
  - `https://www.foodsafetykorea.go.kr/api/openApiInfo.do?menu_grp=MENU_GRP31&menu_no=656&show_cnt=10&start_idx=1&svc_no=I2520&svc_type_cd=API_TYPE06`

### 품목유형코드에서 확인된 계층 예시
- `특수의료용도식품` > `표준형 영양조제식품` > `당뇨환자용 영양조제식품`
- `즉석섭취.편의식품류` > `즉석섭취식품`
- `즉석섭취.편의식품류` > `즉석조리식품`
- `즉석섭취.편의식품류` > `간편조리세트`
- `만두류` > `만두` / `만두피`
- `기타식품류` > `효모식품` / `기타가공품`

### 파싱에 바로 쓰는 규칙
1. 메시지에서 뽑힌 `item_name`을 쿠팡 실거래명(브랜드+제품) 우선으로 유지.
2. 동일 메시지/문맥에서 식품안전나라 유형키워드가 보이면 `item_type_hint`로 보조 라벨링.
3. 최종 표출은 상품명 우선, 유형은 보조(툴팁/서브텍스트)로 처리.

## 4) 상품명 중심 라벨링 초안 (파서 반영 대상)

### A. 면/간편식
- 신라면, 진라면, 짜파게티, 김치사발면
- 라면, 컵라면, 사발면, 볶음면

### B. 즉석밥/가공밥
- 햇반, 즉석밥, 컵밥

### C. 유제품/음료/생수
- 서울우유, 우유, 멸균우유
- 제주삼다수, 생수, 탄산수, 음료

### D. 스낵/과자
- 포카칩, 감자칩, 과자, 시리얼

### E. 국/탕/냉장간편식
- 비비고 사골곰탕, 곰탕, 국, 탕, 즉석국

> 위 라벨은 "알림 분류"가 아니라 "상품명 정규화 후보군"으로 사용.

## 5) 데이터 모델 반영 포인트
- `events_v2` 또는 API 응답 필드에 아래 우선순위 적용:
  1) `item_name` (실상품명)
  2) `change_text` (어떻게 변동됐는지)
  3) `event_type` (PRICE_UP 등 7종 고정 순서)
  4) `item_type_hint` (식품안전나라/카테고리 보조)

고정 이벤트 순서(사용자 규칙):
`PRICE_UP, PRICE_DOWN, SOLD_OUT, RESTOCK, DELAY_NOTICE, NEW_ITEM, NOTICE`

   - 브랜드 사전 + 상품명 사전(쿠팡 관찰명 기반) 추가

2. `src/api.py` `/stats/seller`
   - `item_name` 미검출 시만 `item_type_hint` fallback
3. `data/vendor_aliases.json`
   - 브랜드/상품 별칭(예: 삼다수/제주삼다수, 사골곰탕/비비고 사골곰탕) 확장
