# Spec-Result Drift 운영 체크리스트

## A. 사전 확인 (작업 시작 전)
- [ ] 기준 기획 문서 경로/버전이 명확하다
- [ ] 성공 기준(정량/정성)과 허용 오차가 정의되어 있다
- [ ] 결과물 저장 경로와 파일명 규칙이 정해졌다

## B. 실행 중 드리프트 점검
- [ ] 기획 필수 항목 누락 없음
- [ ] 미승인 기능/내용 추가 없음
- [ ] 핵심 수치가 기획값/허용 오차 내에 있음
- [ ] 사용자 핵심 플로우가 기획대로 동작함
- [ ] 증거(로그/스크린샷/산출물 파일) 수집됨

## C. 불일치 발견 시 즉시 조치
- [ ] Severity(P0~P3) 분류 완료
- [ ] P0/P1은 즉시 확산 차단(배포 중단/플래그 OFF)
- [ ] 수정 담당자/리뷰어/승인권자 지정
- [ ] SLA 타이머 시작 및 마감 시각 기록

## D. 수정/승인/재검증
- [ ] 원인과 수정 범위 문서화
- [ ] 승인 절차 충족(P0/P1: 2인, P2/P3: 1인)
- [ ] 수정 후 재검증 수행(정량/정성/증거)
- [ ] 실패 시 즉시 재수정 루프 진입

## E. 종료 조건
- [ ] 기획값과 결과값 일치 확인
- [ ] 결과물 파일(전/후 비교 포함) 저장 완료
- [ ] 최종 보고에 경로/근거/SLA 준수 여부 포함
