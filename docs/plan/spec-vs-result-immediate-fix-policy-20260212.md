# Spec vs Result Immediate Fix Policy (2026-02-12)

## 1) 목적
기획(Spec)과 실제 결과(Result) 간 불일치가 확인되면, 예외 없이 즉시 수정 강화 프로세스를 자동 적용한다.

## 2) 불일치 정의 (기획값 vs 결과값)
아래 중 하나라도 해당하면 **불일치(Drift)** 로 판정한다.
- **정량 불일치**: 목표 수치/임계값/범위(예: 가격, 수량, 전환율, SLA)가 기획 허용 오차 밖으로 벗어남
- **정성 불일치**: 기획된 UX/카피/정책/플로우와 산출물이 의미상 다름
- **누락/초과 불일치**: 기획 필수 항목 미구현 또는 미승인 기능이 추가됨
- **근거 불일치**: 결과 보고에 재현 가능한 증거(파일/로그/스크린샷/쿼리)가 없음

### 허용 오차 원칙
- 기획 문서에 허용 오차가 명시되면 해당 기준 우선
- 미명시 시 기본 허용 오차는 0(완전 일치)으로 처리

## 3) 즉시 수정 트리거 조건 (심각도/영향도)
불일치 감지 즉시 Severity를 분류하고 자동으로 Fix Mode를 시작한다.

### Severity 분류
- **P0 (치명)**
  - 법적/보안/결제/개인정보/운영중단 리스크
  - 핵심 KPI 또는 사용자 거래에 즉시 악영향
  - 잘못된 결과가 외부 공개/배포됨
- **P1 (높음)**
  - 핵심 기능 동작 오류, 주요 사용자 흐름 저해
  - 리포트/지표의 의미 왜곡 가능
- **P2 (보통)**
  - 비핵심 기능 불일치, 제한적 범위 영향
  - 수동 보정 가능하나 기획과 불일치 명확
- **P3 (낮음)**
  - 문구/표기/경미한 형식 불일치, 영향 미미

### 자동 트리거
- P0/P1: 발견 즉시 배포/확산 중단 + 수정 태스크 강제 생성
- P2/P3: 다음 배치로 미루지 않고 당일 수정 큐 등록

## 4) 수정 SLA
- **P0:** 즉시 착수, 30분 내 1차 완화, 2시간 내 근본 수정 또는 안전 롤백
- **P1:** 2시간 내 수정 완료 또는 롤백, 4시간 내 재검증 완료
- **P2:** 영업일 기준 1일 내 수정 및 재검증
- **P3:** 영업일 기준 3일 내 수정 및 재검증

### SLA 위반 시
- 자동 에스컬레이션(Owner → Reviewer → 최종 승인권자)
- 위반 사유와 재발 방지책을 문서화

## 5) 승인 / 롤백 / 재검증 절차
1. **감지/등록**
   - 불일치 발견 즉시 이슈 등록(증거 파일 경로 포함)
2. **긴급 통제**
   - P0/P1은 즉시 배포 중단 또는 기능 플래그 OFF
3. **수정안 작성**
   - 원인, 수정 범위, 영향도, 롤백 조건 명시
4. **승인**
   - P0/P1: Reviewer + 승인권자 2인 확인
   - P2/P3: Reviewer 1인 확인
5. **적용**
   - 변경 적용 후 결과물 파일/로그 생성 필수
6. **재검증**
   - 기획 체크리스트 기준으로 재검증 수행(정량/정성/증거)
7. **종결**
   - “기획값=결과값” 확인 시에만 종료
   - 미일치 시 3단계(수정안 작성)로 즉시 회귀

## 6) 필수 산출물
- 이슈 기록 1건 이상
- 수정 전/후 비교 결과물 파일
- 재검증 로그 및 승인 기록

## 7) 적용 범위 및 우선순위
- 본 정책은 `priceit-starter` 전 영역에 적용
- 다른 문서와 충돌 시, 본 정책의 즉시 수정/SLA 규칙을 우선 적용
