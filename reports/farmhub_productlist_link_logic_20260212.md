# 팜허브 상품리스트 ↔ 오픈채팅 연동 로직 반영 (2026-02-12)

## 요청
- 오픈채팅방 내용과 팜허브(판매중) 상품리스트를 연동해 상품명을 찾는 로직 강화.

## 반영 내용
1. 판매리스트 기반 term 사전 생성
   - 스크립트: `scripts/build_seller_terms.py`
   - 산출: `data/seller_product_terms_20260212.json` (정규화 매칭 term 565개)

2. API 상품명 추출 로직에 term map 연동
   - 파일: `src/api.py`
   - 적용 순서:
     - (a) 문장 직접 포함 매칭
     - (b) 판매리스트 term map 정규화 매칭(우선)
     - (c) 일반 키워드 정규화 매칭
     - (d) 농산물 패턴 fallback

3. 공지/상태문 오인식 차단 강화
   - 노이즈 키워드 확대(상품/상품별/최고집/전국1위/신상품/특가/필독 등)
   - 안내/공지형 문구를 상품명으로 채택하지 않도록 차단

## 효과(관찰)
- `쥬스용 사과`, `구좌당근`, `표고버섯`, `홍매향`, `흑대추방울토마토` 등 실제 상품명 매칭 증가.
- 동시에 공지문구형 텍스트는 `미분류`로 남겨 오분류를 방지.

## 한계
- 원본 공지 문장이 상품명 없이 올라오는 케이스는 여전히 일부 `미분류`로 남음.
- 추가 개선은 방별 템플릿(최고집/팜허브 문구) 사전 확장으로 진행 필요.

## 관련 파일
- `scripts/build_seller_terms.py`
- `data/seller_product_terms_20260212.json`
